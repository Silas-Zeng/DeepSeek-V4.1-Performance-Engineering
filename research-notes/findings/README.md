# Findings and lessons learned

Use this folder for personal takeaways and bottleneck hypotheses.

Separate three kinds of statements:

- **Observation**: directly visible in a log, trace, benchmark, or source file.
- **Inference**: an explanation supported by several observations.
- **Hypothesis**: a proposed cause that still needs an experiment.

Suggested filename:

```text
YYYY-MM-DD_<topic>.md
```
