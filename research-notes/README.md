# Research notes

This directory stores the working knowledge for the DeepSeek-V4.1 performance project.
It is separate from `docs/`, which describes the repository plan, and from
`results/`, which stores measured experiment outputs.

## Folders

- `technical-reports/`: DeepSeek-V4.1 papers, technical reports, release notes, and short reading summaries.
- `profiling/`: vLLM, PyTorch Profiler, Nsight Systems, and kernel-analysis notes.
- `findings/`: personal observations, hypotheses, bottleneck interpretations, and lessons learned.

## Note format

Every note should record the date, source URL or commit, hardware/software assumptions,
and whether a statement is an observation, an inference, or an unverified hypothesis.
