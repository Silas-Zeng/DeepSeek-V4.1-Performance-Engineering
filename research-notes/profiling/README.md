# Profiling notes

This folder records how to use profiling tools and what each trace shows.

Initial reference:

- [vLLM Profiling Guide](https://docs.vllm.ai/en/latest/contributing/profiling/)

For each profiling session, record the tool and version, framework commit, GPU,
driver, CUDA and PyTorch versions, model, workload, warmup, measured iterations,
trace location, suspected bottleneck, and the evidence for or against the hypothesis.
