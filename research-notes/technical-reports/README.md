# DeepSeek-V4.1 technical reports

Use this folder for reading notes about DeepSeek-V4.1 and related inference
systems. Keep large PDFs outside Git when possible; store the official URL,
date, a short summary, and the parts relevant to performance analysis in
Markdown.

Suggested filename:

```text
YYYY-MM-DD_<short-title>.md
```

Every note should record:

- model or technical-report URL;
- publication or release date;
- the inference path it describes;
- hardware and precision assumptions;
- claimed bottleneck or optimization;
- evidence provided by the authors;
- questions that should be checked with a profiler.

Do not treat an unverified reading note as a benchmark result. Keep source
claims, local observations, and hypotheses separate so later experiments can
update the conclusion without rewriting the history.
